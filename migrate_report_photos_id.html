Migração da tabela report_photos - INT para UUID

⚠️ IMPORTANTE: Execute cada SQL em ordem no phpMyAdmin. Não pule nenhuma etapa.

1. Backup da tabela report_photos

CREATE TABLE report_photos_backup AS SELECT * FROM report_photos;

2. Converter coluna id de INT para VARCHAR(36)

ALTER TABLE report_photos MODIFY COLUMN id varchar(36) NOT NULL;

3. Atualizar valores existentes com UUIDs

UPDATE report_photos SET id = UUID() WHERE id REGEXP '^[0-9]+$';

4. Verificar resultado

SELECT * FROM report_photos LIMIT 5;
